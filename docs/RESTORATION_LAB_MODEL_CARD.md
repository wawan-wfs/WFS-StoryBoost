# Restoration Lab original model card — experimental only

Weights are original from procedural synthetic grayscale images generated by the included trainer; no third-party weights, private photos or external dataset. MIT notice in app/src/main/assets/restoration-lab/LICENSE.txt applies only to the new code/trainer and two original weight files; no repo-wide relicensing. PyTorch is a host-only training dependency, not bundled in APK. Java CPU inference does not require a network or TFLite for this lab. 
Architecture: 1x3x3 conv to 4 channels, ReLU, 4x3x3 conv to 1 channel, residual add, clamp [0,1], replicated border. 77 FP32 weights/biases. Deblur trained on horizontal 7-pixel box blur. SR2x trained on 2x box downsample + bilinear enlargement; model improves pre-upscaled luma, not arbitrary 4x neural SR. Color preview uses luminance delta on RGB; real photo/alpha/chroma fidelity not validated. Input size capped at 512 for deblur, 256 before 2x SR. 
Training: Python 3.13.5, torch 2.10.0+cpu, seed 211, 96 train cases, 240 Adam steps, independent 24 case holdout seed 9211. Run python scripts/train_restoration_lab.py --out /tmp/wfs-lab-experiment (never overwrite bundled weights automatically). Exact weights SHA:

- SR2x: dea96181a956528cfff99cdf94856f5b2a594ed72e467f025e0c4dab99483b01

Java first-run full 64x64 inference ~7.80ms / 5.87ms, all 4096 outputs compared to PyTorch max absolute error 5.96e-8 / 1.19e-7. 144 local model assertions pass including SHA rejection, finite bounds, interruption and bilinear shape. No production activation: Deblur improvement is weak and some cases degrade. Need bicubic and real consented photo comparisons, independent test corpora, SSIM, perceptual fidelity, latency/PSS on physical ARM64, no ringing/face drift, full-res tiling and stable quality thresholds. ## Beta23 memory-bounded inference
All four pinned models unchanged. Exact tiled CPU convolution uses core 128 and two-pixel halo, replicated outer padding, 1024px experimental preview. Hidden activation array is at most 132*132*4 floats (~272 KiB), versus 16 MiB for 1024x1024 untiled; full input/output and bitmap buffers still scale with image size. Host test compared 337948 float values bit-identically across four models and five shapes, plus two 1024x720 refined inferences (52.941/86.445ms single host samples) and cancellation. No new quality training/claim, no physical ARM64 results, prior photo SSIM limitations unchanged. Device tests mandatory but pending.
