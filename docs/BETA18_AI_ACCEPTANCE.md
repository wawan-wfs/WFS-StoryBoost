# Offline AI Deblur and Super-Resolution: evidence gate

Existing DnCNN denoise and portrait features retained; do not rename sharpening or interpolated enlargement as learned deblur/SR. New models are not activated in this candidate. Require artifact URL, model SHA-256, exact license for weights AND redistribution, input/output shapes, preprocessing, supported TFLite ops, quantization and documented output scale. Reject models with unverified redistribution rights or network inference.

Build a consented, locally stored paired benchmark: clean synthetic edges/text/textures plus blur/noise and downsampling; real low-light and moving portrait inputs with user consent and no upload. Record baseline bicubic SR and existing non-neural enhancement against candidate at 1x/2x output; compare PSNR/SSIM, edge ringing and face fidelity; report failures not only successes. Measure P50/P95 latency, peak RSS/PSS, thermal and allocation failure on API29/35 and physical ARM64, tile boundary seams, cancellation, immutable source hash, low-memory fallback. Require side-by-side original/processed/ground-truth crops, reproducible seeds, pinned version and no hallucination claim. No production activation before all independent gates and user consent for portrait tests.

## Executable synthetic baseline

Run `python3 tests/test_restoration_benchmark.py -v` and `python3 scripts/restoration_benchmark.py --out /tmp/storyboost-restoration`. Eight grayscale cases use deterministic edges, texture, lines and gradients. Motion blur input is compared to unmodified degraded input; 2x SR input uses 2x box-downsample and bilinear baseline. Report includes exact input/truth SHA-256, PSNR and explicitly labeled non-overlapping 8x8 SSIM. Optional `--candidates DIR` scores exact-size PGM outputs against the same references; this does not run a model. Three harness tests passed locally; identity oracle is a ground-truth copy, not neural inference. Baseline PSNR dB: deblur edges 22.56, texture 10.63, lines 12.71, gradient 27.32; SR edges 29.08, texture 15.03, lines 14.66, gradient 30.57. Physical benchmarks, bicubic comparison, real photos, model selection and license verification remain open.
